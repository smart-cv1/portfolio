مهندس برمجيات | مشروع شخصي | 2024 – 2025 • تطوير نظام إدارة شحن السيارات الكهربائية باستخدام Flutter وASP.NET Core، شمل بناء وتكامل واجهات برمجة التطبيقات RESTful لحجز وإدارة المستخدمين، وتطبيق نظام تحقق من المركبة عبر QR، وتصميم بنية قابلة للتوسع تدعم تعدد الأدوار. • تنفيذ لعبة تعليمية تفاعلية (Code Clash) باستخدام Flutter وربطها بخدمات الخلفية عبر ASP.NET Core، شملت تصميم منطق اللعبة وواجهة مستخدم استجابية، وتحسين الأداء لضمان سلاسة اللعب. • إنشاء تطبيق تجارة إلكترونية متكامل (SO CHIC) على الهواتف المحمولة، دمج واجهات برمجة التطبيقات للمنتجات والطلبات وإدارة المستخدمين، وتطبيق ميزات السلة، قائمة الرغبات، وتتبع الطلبات، مع تصميم واجهة نظيفة وسهلة الاستخدام. • تطوير نظام إدارة مطعم باستخدام ASP.NET Core وSQL Server، بناء واجهات برمجة التطبيقات لمعالجة الطلبات والطاولات وبيانات القائمة، تحسين كفاءة سير العمل عبر الأتمتة، وربط الواجهة الأمامية بالخدمات الخلفية. • بناء تطبيق إدارة موظفين باستخدام Flutter وFirebase، تنفيذ المصادقة وقاعدة بيانات Firestore، تمكين التحديثات الفورية للبيانات وإعداد تقارير، وتعزيز قدرات تتبع وإدارة الموظفين. • تصميم لعبة مغامرة ثنائية الأبعاد باستخدام Unity وC#، تنفيذ حركة اللاعب، الذكاء الاصطناعي للأعداء، وتصميم المستويات، بالإضافة إلى آليات اللعبة وأنظمة الاصطدام.
