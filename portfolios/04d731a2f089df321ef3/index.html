من أنا

مهندس برمجيات متخصص في تطوير التطبيقات الكاملة باستخدام Flutter و ASP.NET Core، مع خبرة في بناء أنظمة قابلة للتوسع وتكامل واجهات برمجة التطبيقات. أثبت قدرته على delivering حلول end‑to‑end تشمل منصات التجارة الإلكترونية، أنظمة إدارة، وتطبيقات تتبع زمني حقيقي. يتميز بمهارات قوية في تصميم architectures نظيفة، تحسين الأداء، وتكامل خدمات السحابة مثل Firebase. يسعى باستمرار لتقديم تجارب مستخدم عالية الجودة وحل التحديات التقنية المعقدة.

عمل حر

• تطوير نظام إدارة شحن المركبات الكهربائية باستخدام Flutter و ASP.NET Core، مع بناء ودمج RESTful APIs للحجز وإدارة المستخدمين، وتنفيذ نظام تحقق المركبات基于 QR، وتصميم بنية قابلة للتوسع تدعم أدوار متعددة. — • تحسين أداء النظام وضمان تكامل سلس بين الواجهة الأمامية والخلفية، مع إجراء اختبارات تكامل وتوثيق API لضمان الجودة. — مطور ألعاب تفاعلية — عمل حر — • تطوير لعبة برمجية تفاعلية (Code Clash) باستخدام Flutter ودمج خدمات الخلفية عبر ASP.NET Core، مع تنفيذ منطق اللعبة وتصميم واجهة مستجيبة. — • تحسين أداء اللعب لضمان سلاسة التجربة وتقليل زمن الاستجابة عبر تحسين حالة الحالة وإدارة الموارد. — مطور تطبيق تجارة إلكترونية — عمل حر — • إنشاء تطبيق تجارة إلكترونية حديث (SO CHIC) باستخدام Flutter، مع دمج APIs للمنتجات، الطلبات وإدارة المستخدمين، وتنفيذ ميزات السلة، قائمة الأمنيات وتتبع الطلبات. — • تصميم واجهة مستخدم نظيفة وسهلة الاستخدام، مع تحسين تجربة المستخدم وضمان استجابة سريعة على مختلف الأجهزة. — مطور نظام إدارة مطاعم — عمل حر — • تطوير نظام إدارة مطاعم باستخدام ASP.NET Core و SQL Server، مع بناء APIs لمعالجة الطلبات، الطاولات وقائمة الطعام، وتحسين كفاءة سير العمل عبر أتمتة العمليات. — • دمج الواجهة الأمامية مع الخدمات الخلفية وضمان أمان البيانات وتكامل سلس بين المكونات. — مطور تطبيق إدارة الموظفين — عمل حر — • بناء تطبيق إدارة الموظفين باستخدام Flutter و Firebase، مع تنفيذ المصادقة وقاعدة بيانات Firestore وتمكين التحديثات الفورية للبيانات وإعداد التقارير. — • تعزيز قدرات تتبع وإدارة الموظفين من خلال لوحات تحكم تفاعلية وتنبيهات في الوقت الحقيقي. — مطور لعبة ثنائية الأبعاد — عمل حر — • تطوير لعبة ثنائية الأبعاد في Unity باستخدام C#، مع تنفيذ حركة اللاعب، ذكاء الاصطناعي للأعداء وتصميم المستويات. — • تصميم ميكانيكيات اللعبة وأنظمة الاصطدام، مع تحسين الأداء وضمان تجربة لعب سلسة.
